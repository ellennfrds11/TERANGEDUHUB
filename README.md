TERANG EduHub merupakan media edukasi digital yang dikembangkan oleh mahasiswa KKN Giat 16 Universitas Negeri Semarang sebagai sarana pembelajaran mengenai efisiensi penggunaan energi listrik bagi pelaku UMKM di Kelurahan Genuk. Materi edukasi, asesmen mandiri, kuis, serta media pendukung dapat diakses kapan saja.
